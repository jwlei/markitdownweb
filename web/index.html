Questions

Are my files uploaded anywhere?

No. MarkItDown runs inside your browser using WebAssembly (Pyodide). Files are read locally and never sent to a server.

Why is the first conversion slow?

The first visit downloads a Python runtime and the conversion libraries (about 30 MB). Your browser caches them, so later visits start much faster.

What doesn't work in the browser?

Features that need native tools or cloud services: image OCR and EXIF metadata, audio transcription, YouTube transcripts, and cloud document analysis. Use the MarkItDown Python package for those.
